# Zozo Chat

AI for creatives, from **Zozo AI, Inc.** Formerly known as Zodiac.

Zozo Chat combines AI conversations, customizable personas, roleplay, and image generation and editing. It uses local-first browser storage with optional encrypted cloud sync. Chat models are available through OpenRouter and optional Gemini API keys; hosted image generation and editing use Runware.

[Open Zozo Chat](https://chat.zozo.sh/) · [Source code](https://github.com/zozo-ai-inc/zodiac)

## Development

The frontend is built with Vite and TypeScript. Development happens on `main`; the permanent `production` branch tracks production deployments. Contributions are welcome.

```sh
git clone https://github.com/zozo-ai-inc/zodiac.git
cd zodiac
npm install
npm run dev
```

Other useful commands:

```sh
npm run build       # Type-check and build for production
npm run lint        # Run ESLint
npm test            # Type-check and run the Vitest suite
npm run test:e2e    # Run the Playwright browser suite
```

See [AGENTS.md](AGENTS.md) for architecture, contribution conventions, and the release workflow.
