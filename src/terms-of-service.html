Local storage does not mean AI generation happens on your device: content needed for a request is still transmitted for processing.

Optional Cloud Sync encrypts supported data on your device using a separate encryption password. Keep that password safe; we cannot recover it or decrypt the stored content for you. Account login, profile details, billing information, and operational metadata are separate from this encrypted content. The Privacy Policy explains these boundaries.

Cloud Sync requires an eligible plan. When an eligible subscription ends, the current expiry flow provides a seven-day final-download window measured from the recorded subscription period end. After that window, the cloud copy is eligible for deletion. Export what you need before access ends; Cloud Sync is not permanent archival storage.

Use Settings → Data Management to export a takeout file or import supported files. Choose the categories you need and review the result for omissions or errors. Takeout files contain readable data, including any API keys you expressly select. Store and share them carefully. Imports may create copies or overwrite selected records according to the choices shown in the importer.

The move from Zodiac's old domain to Zozo Chat does not automatically move browser-local data or login sessions. Users with local data can export and import it; Cloud Sync users can sign into the same account and unlock their cloud data on the new domain. The transition does not itself delete the old browser's data. Keep your own backup of important material.
